Protocol Architecture

Three Pillars. Zero PII on Chain.

No personal information ever hits the blockchain. The guardian’s browser derives AES-256-GCM keys locally from a private passphrase. The protocol only ever notarizes hashes, nullifiers, and jurisdiction rule bindings.

Court-Ready Evidence

Deterministic Evidence Chain (DEC v2)

Every erasure operation generates a DEC v2 certificate containing statutory references (COPPA, MODPA, GDPR, DPDP), actor authority, and per-item nullifiers. Its core hash is pinned immutably on chain.

Dual-Notary Ratchet

One obligation. Two independent notary paths.

Every erasure request must originate from the guardian's wallet. Execution is witnessed either by the Attestor service via EIP-191 signatures or by Chainlink CRE Consensus via onReport().
